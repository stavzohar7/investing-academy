# 📈 אקדמיית המשקיע — מאפס ועד באפט

קורס חינמי בעברית ללימוד השקעות במניות — לטווח ארוך ולסווינג — בדרך של וורן באפט, צ'רלי מאנגר ופיטר לינץ'.

- 14 שלבים ו-50 שיעורים (כ-20–25 דקות כל אחד) עם בחנים, סיכום ומשימות מעשיות, משימות מעשיות, מבחני שלב ופרויקט גמר
- ניתוח שבועי של 10 מניות, עם כרטיס ביצועים שקוף מול המדד
- מחשבונים (DCF, גודל פוזיציה, יחסים פיננסיים, עצמאות כלכלית), סימולטור סווינג, יומן מסחר ורשימת מעקב
- נגיש, מותאם לטלפון, ועובד גם בלי אינטרנט אחרי הביקור הראשון

ההתקדמות נשמרת בדפדפן של כל משתמש בלבד (אפשר לגבות ולשחזר מתוך "ההתקדמות שלי").

**האתר נועד ללימוד בלבד ואינו מהווה ייעוץ השקעות, שיווק השקעות או המלצה לקנות או למכור נייר ערך כלשהו.**

## הרצה מקומית

```
node serve.js
```
