# איך מוסיפים סרטוני שיעור

1. פתחו באתר את העמוד `#scripts` — שם יש תסריט מוכן (טיוטה) לכל שיעור, עם כפתור "העתק".
2. הדביקו את התסריט בכלי להפקת סרטון עם דמות מדברת (למשל HeyGen, Synthesia, D-ID או כלי דומה) ובחרו קול עברי. עברו על הטקסט לפני ההפקה — זו טיוטה שנבנתה אוטומטית מתוכן השיעור.
3. שמרו קובץ mp4 בתיקייה `video/` בשם מזהה השיעור (למשל `l1-1.mp4`), או העלו ליוטיוב.
4. הוסיפו שורה ל-`video/manifest.js` (הדוגמה בתוך הקובץ).
5. הוסיפו את הקובץ לרשימת `CORE` ב-`sw.js` רק אם רוצים שיעבוד גם בלי אינטרנט (קבצי וידאו גדולים — עדיף לא).
6. `git add video && git commit && git push`.

שימו לב: כלי הפקת וידאו מסחריים הם בתשלום ויש להם תנאי שימוש משלהם; בדקו אותם לפני פרסום.
