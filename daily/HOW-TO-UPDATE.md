# מהדורה יומית — איך מעדכנים

המהדורה מסכמת את יום המסחר הקודם בוול סטריט. מבוצע על ידי המשימה המתוזמנת `investing-app-daily-news` (ג׳–ש׳ בבוקר), אבל אפשר גם ידנית.

1. **מחקר:** חפשו (WebSearch) את סגירת השוק של יום המסחר האחרון ואת המניות שהיו בחדשות. קראו לפחות שני מקורות (WebFetch). העדיפו מקורות ראשוניים: הודעות חברות, SEC, CNBC, Reuters.
2. **אימות:** כל מספר — בשני מקורות לפחות. אם יש סתירה: כתבו "בערך" וטווח, או השמיטו. מקור אוטומטי שסותר את כולם — לא נכלל. נתון ממקור יחיד מסומן בשדה `verified` ("לא אומת מול הודעת החברה").
3. **כתיבה:** העתיקו את `daily/2026-11-17.js` כתבנית, בשם `daily/YYYY-MM-DD.js` (תאריך יום המסחר). בניסוח שלכם, בלי העתקת משפטים ממקורות. 3–6 סיפורים. לכל סיפור: מה קרה, למה (לפי הדיווחים — לא כעובדה), "איך לחשוב על זה" (עדשה לימודית, לא המלצה), מקורות עם קישורים, ושדה `verified`.
4. **אסור:** להמליץ לקנות/למכור/להחזיק; לצפות לאן המחיר ילך; להמציא סיבה. אם לא ידוע למה — כתבו שלא ידוע.
5. **רישום:** הוסיפו את המהדורה בראש `daily/manifest.js`; הוסיפו את הקובץ ל-CORE ב-`sw.js` והעלו את מספר הגרסה של ה-CACHE.
6. **בדיקה:** פתחו `#news` בדפדפן, ודאו שאין שגיאות קונסולה ושאין גלישה אופקית בנייד.
7. **פרסום:** `git add daily sw.js && git commit && git push` (זהות "Investing Academy").
8. אם נמצאה טעות בעבר — תקנו ורשמו ב-`trust.js` (ERRATA).

## מקורות מומלצים (לקרוא, לסכם בעברית בניסוח עצמאי ולקשר — לא להעתיק)
- אמריקה: CNBC, Reuters, Yahoo Finance, MarketWatch, Barron's, Investing.com, TradingView, Motley Fool, Seeking Alpha; מקורות ראשוניים: הודעות חברות, SEC EDGAR.
- ישראל: גלובס, כלכליסט, דה-מרקר, הבורסה לניירות ערך (TASE).
- מקורות במנוי (Bloomberg, WSJ, FT): רק כותרות פומביות, לא לצטט תוכן.
- בלוק אופציונלי `israel: { headline, points: [..], sources: [{t,u}] }` למה שהזיז את הבורסה בתל אביב ושער הדולר.
- שדה אופציונלי `updated: "HH:MM"`.
- מהדורת ערב (לפני פתיחת המסחר): מזהה `YYYY-MM-DD-pre` (למשל 2026-11-19-pre), עם מה שקרה בלילה, דוחות שצפויים היום ונתוני פרי-מרקט.
- האתר בודק אוטומטית כל 10 דקות אם פורסמה מהדורה חדשה ומציג למשתמש הודעה "מהדורה חדשה".
